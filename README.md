# Deep Learning & Neural Network

This repository contains various projects and lab reports related to deep learning, neural networks, and fundamental mathematical concepts essential for AI and machine learning.

### 1️⃣ TensorFlow Fundamentals

- Introduction to **TensorFlow** and its core functionalities.
- Covers tensors, operations, and computational graphs.

### 2️⃣ Loss Function

- Understanding different **loss functions** used in machine learning.
- Implementation of MSE, Cross-Entropy, and other loss functions.

### 3️⃣ Math

- Essential **mathematical concepts** for deep learning.
- Covers matrix operations, differentiation, and linear algebra basics.

### 4️⃣ Activation Function

- Exploration of various **activation functions** like ReLU, Sigmoid, and Tanh.
- Understanding their impact on neural networks.

### 5️⃣ Gradient Descent

- Implementation of **Gradient Descent** and its variants (SGD, Adam, RMSprop).
- Optimizing neural networks for better performance.

### 6️⃣ Neural Network

- Building a **fully connected neural network** from scratch.
- Understanding backpropagation and weight updates.

### 7️⃣ Digit Classification

- Implementing a **digit classification model** using deep learning.
- Training a neural network on the MNIST dataset.

### 8️⃣ Convolutional Neural Networks (CNNs)

- Introduction to **CNNs** and their role in image processing.
- Implementing convolutional layers for feature extraction.

## 🔧 Requirements

Ensure you have the following dependencies installed:

- Python 3.x
- TensorFlow
- NumPy
- Matplotlib
- Pandas
- Scikit-learn
- Jupyter Notebook (optional)

Install dependencies using:

```bash
pip install tensorflow numpy matplotlib pandas scikit-learn jupyter
```

## 🚀 Usage

Clone the repository and navigate to the project directory:

```bash
git clone https://github.com/beniamine3155/deep_learning_tensorflow
cd deep_learning_tensorflow
```

Run the respective scripts or Jupyter notebooks inside each project folder to explore the implementations.
